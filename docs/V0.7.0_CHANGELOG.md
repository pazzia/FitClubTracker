# FitClub 0.7.0

Объединённая версия основного приложения; versionCode 17, applicationId com.fitclub.tracker.

Интегрирован workout-flow: несколько тренировок на дату, просмотр и редактирование результатов, общий тоннаж, удаление с подтверждением, обзор активной тренировки, произвольный порядок упражнений, добавление/удаление, единые кнопки 56 dp.

Сохранены ранее объединённые исправления атласа, фотографий, светлой и тёмной тем.
Room schema повышена до 6 с миграцией существующих данных.
README актуализирован и фиксирует main как единственный продовый источник.
Экспериментальный идентификатор и название APK удалены.

Известные ограничения: нет восстановления незавершённой тренировки после уничтожения процесса; некоторые отчёты остаются в кг; изменение результатов пока не пересчитывает логи времени отдельных упражнений.
