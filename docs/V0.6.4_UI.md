# FitClub 0.6.4

- White Day is a persistent profile theme with a white background, dark readable text, light surfaces and matching system bars. Existing dark themes remain selectable.
- Program deletion opens a confirmation dialog naming the program; cancellation or dismissal does not delete.
- The library home and muscle-group lists search exercise names, groups, equipment and muscle names. Russian е/ё and case are normalized; all query words must match. Results open exercise details. The picker shares matching logic.
- Program exercise cards show the same technique thumbnail as the exercise catalog alongside the title.
- Tests cover theme switching and preference persistence, cancel/confirm deletion, normalized multiword search and the thumbnail after adding an exercise.
