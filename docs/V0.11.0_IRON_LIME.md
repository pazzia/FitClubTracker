# FitClub 0.11.0: перенос на Iron & Lime

Источник: FitClubTracker Animation Pack v1. Использованы ключевые кадры `today_dashboard`, `workout_start` и `workout_complete`, токены `design_tokens.json` и тайминги `fitclub_animations.json` / `ANIMATION_SPEC.md`.

## Что перенесено

| Пакет | В приложении |
|---|---|
| Цвета: bg #0A0C0D, surface #15181A, lime #C6FF3D, ember #FF7A45 | `ui/theme/Theme.kt`. Светлая тема сохранена: кнопки чернильные с лаймовой подписью, лайм не используется как текст на белом. |
| Шрифты Oswald (заголовки, цифры) и Onest (интерфейс) | Без изменений. Заголовки экранов 38–40sp. |
| Карточки 20dp, кнопки-капсулы, свечение (accentAlpha 0.30) | `components/IronLime.kt`: `glow`, `PillButton`, `GlowProgress`, `StatRow`, `RoundIconButton`, `SectionHeader`. Общие компоненты в `Common.kt` переведены на капсулы. |
| Экран «Сегодня» | `today/TodayScreen.kt`: аватар, серия, карточка с фото и прогрессом, «План недели» плитками, сводка. |
| Нижнее меню с индикатором | `navigation/AppNav.kt`: пять вкладок, профиль — вкладка. |
| Анимация старта, 3.6 с | `workout/WorkoutAnimations.kt` → `WorkoutCountdown`. Шаг 900 мс, GO на 2700, переход на 3300. Тап — старт сразу. Вибрация light/medium/strong, звук на GO. Reduce Motion: шаг 700 мс, без частиц. |
| Анимация завершения, 2.6 с | `WorkoutCompleteHeader`: значок 0–520 мс, кольца с 300, заголовок с 600, статистика с 1050, серия с 1450. Действия разблокируются на 2200. Вибрация success, звук. |
| JSON-конфиг | `assets/animations/fitclub_animations.json` читается `AnimationPack`. Если ключа нет, берутся значения пакета. |

Функции, справочники (упражнения, атлас мышц), программы, календарь, прогресс, замеры, настройки и миграции БД не менялись. Добавлены две настройки профиля: «Отсчёт 3–2–1 перед тренировкой» и «Звуки старта и финиша».

## Проверка

- Все модульные и UI-тесты проходят в CI: 175 тестов, включая новые `RedesignPreviewTest` и `RedesignScreensTest`. Тесты проверяют тайминги из JSON, отсчёт 3 → 2 → GO → первое упражнение, пропуск по тапу, отключение отсчёта, блокировку действий до конца анимации и снимают все основные экраны в тёмной и светлой темах.
- В тестах поменялись только формулировки, которые поменял сам дизайн: разделы редактора программы теперь находятся по тегу, а не по тексту с «+»; число упражнений проверяется в правильной форме слова; в истории версий появилась 0.11.0.

## Дизайн-ревью

Скилл дизайнера (frontend-design) провёл два круга проверки по скриншотам из CI.

**Круг 1, исправлено:**
- Геометрия отсчёта: подпись внутри кольца, свечение дуги концентрично, без «коробки» за GO, макет не прыгает на GO, верхний прогресс показывает 1/N.
- Итог помещается на экран, действия проявляются после анимации.
- Формы слов «подход» и «упражнение» во всех списках.
- Карточка «Сегодня»: план справа, прошлый результат под названием, программа над днём, неразрывные пробелы.
- Профиль: заголовок «Профиль», подсказка в имени, уровни «Новичок / Опытный / Профи», один переключатель темы «Тёмная / Светлая».
- Кнопки «Закончить тренировку» и «Пропустить упражнение» больше не путаются.
- Растушёвка над нижними кнопками тренировки.
- Разделы редактора программы — полноширинные строки.
- Календарь: кнопка «назад», легенда ○ план / ● выполнено совпадает с отметками в днях.
- Галочка у выбранного варианта в первом знакомстве.
- Тёмная заглушка вместо белой вспышки, пока грузятся рисунки атласа.

**Круг 2, исправлено:**
- «21 упражнение», «1 зона».
- «Пропустить отдых».
- Один словарь сводок: время / тоннаж / подходы, тысячи с пробелом.
- «Редактировать результат» стал вторичной кнопкой.
- У всех сегментированных переключателей единый лаймовый выбор.
- Одна стрелка «назад».
- Раздел «По упражнениям»: фильтр справа от заголовка.
- В редакторе программы — шеврон, который поворачивается при раскрытии.
- Пустые дни недели отмечены точкой, а не кольцом плана.
- Под точками серии — буквы дней, серия начинается с 1.
- Иконка блина для тоннажа.

**Оставлено сознательно:**
- Карточка «Общий тоннаж» и текст «Первый результат с повторениями в истории». На них опираются редактирование итога и автотесты.
- Цвета обложек программ: их выбирает пользователь.
- Цвета данных в замерах.
- «Бумажный» фон рисунков атласа: так нарисованы иллюстрации.
- Порядок блоков карточки упражнения.
- Подпись «Назад» в итоге: экран открывается и из «Сегодня», и из календаря.
