# Иллюстрации

Референсы пользователя: man.png, Fam.png, manfam2.png. Использован встроенный image_gen; окончательные ассеты сохранены в app/src/main/res/drawable-nodpi. Для карточек используются отдельные кадры, для общей схемы — парные проекции. Фон тёмный, прозрачная вырезка не применяется; устаревшие SVG-маски не накладываются на новые изображения.

Последняя правка (precise-object-edit): добавить синюю закраску внешних косых мышц по обеим сторонам красной прямой мышцы живота; сохранить позу, пропорции, одежду, освещение и тёмный фон; гладкие границы, без текста и цветного мусора. Мужской кадр ограничен областью живота. Женский вариант сохраняет непрозрачную спортивную одежду.

Общая схема (scientific-educational): четыре спортивные фигуры, мужчина спереди/сзади и женщина спереди/сзади; цветные основные мышечные зоны, тёмная спортивная одежда, убрать подписи, гладкие контуры на фоне #14191d.

Атласы: 12 областей в исходном порядке, цветные мышцы, гладкие контуры на тёмном фоне, без подписей. Женский атлас — цветные зоны поверх закрытой спортивной одежды. После генерации применялись только кадрирование, масштабирование и WebP-кодирование.
