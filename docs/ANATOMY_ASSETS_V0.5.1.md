# Исправление атласов 0.5.1

20 карточек (индексы 0–7, 10–11 для каждого пола) заново вырезаны из исходных пользовательских man.png и Fam.png. Каждая область ограничена своими границами: фрагменты соседних строк и подписи не включены. Все карточки 400×400 WebP, фон #14191d. Проверены квадратная сетка и отображение в прямоугольных карточках с ContentScale.Fit.

Картинки ягодиц group_male_8.webp и group_female_8.webp не изменены, проверено совпадение SHA-256 до и после обработки. Квадрицепсы group_male_9.webp и group_female_9.webp из версии 0.5.0 уже корректно вырезаны и тоже сохранены. Общие карты тела не изменены.

Причина дефекта: предыдущие файлы содержали края соседних областей атласа; переход на Fit сделал их видимыми. Исправлены исходные ресурсы, без генерации новых изображений и без изменения цветов мышц.
