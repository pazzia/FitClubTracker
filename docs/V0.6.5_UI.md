# FitClub 0.6.5

- Only «Светлая» and «Темная» are offered. White Day migrates to light; previous dark and pink themes migrate to dark with blue accents.
- All 448 source photographs and full-resolution contour masks are available offline. Both detailed photos and thumbnails use the same foreground contrast and background fading, without painting rectangular regions around equipment.
- Asset preparation uses pinned BiRefNet fine mattes, Grounding DINO object proposals, and MobileSAM silhouettes with foreground/background points. Multiple silhouettes are compared against the fine matte. Only equipment near the athlete is retained; bench detection is restricted to relevant exercises.
- The segmentation models run only during asset preparation. Their weights and inference code are not included in the APK.
- Release masks are committed with source and mask SHA-256 values in exercise_masks/manifest.json. Ordinary CI validates those hashes and runs Android tests; it does not regenerate masks or rely on expiring workflow artifacts.
- The native Android renderer exports all 448 frames as contact sheets plus representative large/thumbnail previews. Visual inspection is required in addition to size and coverage checks.
- Source photos are pinned to free-exercise-db f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5. Grounding DINO is pinned to a2bb814dd30d776dcf7e30523b00659f4f141c71; MobileSAM to f706ad9c4eb7f219c00d9050e46328518ffb65d2 with checkpoint SHA-256 6dbb90523a35330fedd7f1d3dfc66f995213d81b29a5ca8108dbcdd4e37d6c2f.
- For regeneration, prepare fresh BiRefNet baseline masks using scripts/prepare_exercise_masks.py in a clean asset-preparation workspace, then run scripts/prepare_semantic_masks.py with the desired shard selection. Review regenerated images before replacing release assets; do not use released masks as a fresh baseline.
