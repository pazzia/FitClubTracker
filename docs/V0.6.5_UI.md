# FitClub 0.6.5

- Profile offers only «Светлая» and «Темная», with blue accents. Existing White Day settings migrate to light; former dark themes migrate to dark. Legacy accent values cannot restore removed themes.
- All 448 technique photographs use full-resolution foreground mattes, shared by detailed photos and thumbnails. Athlete and salient equipment retain colour/contrast; background has reduced saturation, contrast and opacity. Gaps are masked per pixel; no rectangle is used to preserve equipment.
- Contours are generated at build time using pinned BiRefNet general-lite weights (upstream BiRefNet MIT license). The model is not included or executed on phones, and source photos/poses are unchanged.
- Both technique frames are processed. Edge padding is trimmed using the original image; fit scaling preserves equipment and the entire athlete.
- Tests cover old theme migration, contour holes/detached equipment, padding and 448 aligned masks. Native Android renderer exports representative large/small previews for visual review before merge.
