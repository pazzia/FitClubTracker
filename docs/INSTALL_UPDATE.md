# Установка и перенос данных

Прежний CI создавал новый тестовый ключ при каждом запуске. APK 0.2.0 и новая сборка имеют разные подписи: обычная установка поверх старой версии может завершиться INSTALL_FAILED_UPDATE_INCOMPATIBLE. Удаление приложения стирает его локальные данные. В новом CI ключ кэшируется для следующих тестовых обновлений.

Если данных нет, старую debug-версию можно удалить перед установкой. Если нужно сохранить программы, историю и профиль, используйте tools/transfer_debug_data.py на компьютере с Python 3 и Android platform-tools (adb). Включите USB-отладку и разрешите подключение компьютера на телефоне. Должен быть подключён ровно один авторизованный телефон. Скрипт предназначен для debug-сборок FitClub.

По умолчанию скрипт только сохраняет базу, WAL/SHM и профиль в новую папку и проверяет контрольные суммы:

    python tools/transfer_debug_data.py

Если указан --apk, сначала пробуется обычное обновление без удаления. Переустановка допускается только с явным --allow-reinstall и после проверки резервной копии:

    python tools/transfer_debug_data.py --apk FitClub-v0.3.0-build8-debug.apk --allow-reinstall

Укажите фактическое имя скачанного APK. При отличающемся расположении adb добавьте --adb путь-к-adb. После переноса скрипт сверяет данные, запускает приложение, а миграция Room обновляет схему. Сохраняйте резервную копию до проверки данных в приложении. USB-перенос на реальном телефоне в этой среде не проверялся.

## Подпись новых версий

Начиная со сборки №8 CI требует сохранённый ключ и проверяет отпечаток из docs/debug-signing-sha256.txt. Потеря ключа останавливает сборку вместо создания несовместимого APK. applicationId остаётся com.fitclub.tracker, versionCode возрастает.

Для постоянного хранения workflow поддерживает Actions secret FITCLUB_DEBUG_KEYSTORE_BASE64. Он должен содержать Base64 **того же** debug.keystore, которым подписана сборка №8. Новый случайный ключ не подходит; публичный сертификат APK не восстанавливает закрытый ключ. Сейчас используется CI-кэш fitclub-debug-signing-v1; постоянный secret ещё не настроен.

USB-скрипт предназначен для переноса старых баз и профиля; фотообложки новой версии он не копирует. При обычном обновлении APK с совпадающей подписью фото остаются в личных файлах приложения.
