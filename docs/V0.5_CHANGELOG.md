# FitClub 0.5.0

- Выбор программы в календаре открывает полноценную страницу программ и возвращает выбранную программу в исходный план. Можно создать новую программу и затем выбрать её.
- Четыре карточки ягодиц/квадрицепсов вырезаны из пользовательских man.png и Fam.png. Размер 400×400, WebP, фон #14191d. Цвет мышц сохранён из источников: ягодицы красно-оранжевые, квадрицепсы фиолетовые. Генерация изображений не использовалась.
- Одинаковое место для кнопок отметки/удаления в каждой строке. Ширина полей не меняется при добавлении и выполнении подходов; высота 56 dp.
- Отдельное завершение упражнения с тоннажем, временем, самым тяжёлым выполненным подходом и сравнением с максимальным весом за всю предшествующую историю данного упражнения. При равном весе сравниваются повторения. Нагрузка в фунтах конвертируется для хранения в килограммы.
- Для упражнений на время показываются секунды, а не фиктивный тоннаж.
- Свободные переходы назад/вперёд с возвратом к сохранённым в текущей тренировке строкам и прокруткой к началу упражнения. Повторяющиеся упражнения не делят строки между собой.
- Завершение всей тренировки доступно сразу, в том числе без подходов. Подтверждение явно сообщает количество сохраняемых выполненных подходов. Выход кнопкой Android также предлагает сохранить результат.
- Завершённая или неполная тренировка сохраняет отмеченные подходы, время сессии, время и статус каждого посещённого упражнения. В календаре отображаются детали упражнений.
- База данных 4→5 обновляется без удаления истории; добавлены exercise_logs и признак isTimed для set_logs. Старые подходы сохраняются как обычные подходы.
- Стартовый экран ждёт фактической инициализации справочника/программ, отображает ошибки с повтором, версию и список изменений. После обновления пользователь закрывает release notes кнопкой «Продолжить»; в обычные запуски экран автоматически закрывается после загрузки (минимум 800 мс).

Время упражнения включает отдых и просмотр техники, пока это упражнение открыто. При переходе к другому упражнению или завершении таймер останавливается. Статистика учитывает только отмеченные выполненными подходы. Сохранение в постоянную историю происходит при завершении тренировки.
