# FitClub 0.8.0-test: реализация UX/UI ревью

Тестовая ветка `fork/ux-review-0.8.0`, PR #10. База: main 0.7.0.
Килограммы остаются канонической единицей хранения. Фунты — представление; переключение не переписывает результаты. Коэффициент: 1 кг = 2.2046226 lb. Открытые редакторы и активная тренировка фиксируют единицы ввода, чтобы уже введённые числа не сменили смысл. Неизменённый вес при сохранении результата сохраняет точное исходное значение, несмотря на округление отображения до десятых.

## Проверки и ограничения

Автоматические тесты охватывают миграции схем 1–6 в 7, кг/фунты и точное сохранение неизменённых значений, независимые блоки повторяющихся упражнений, снимок названия, транзакцию завершения, сохранение черновика при ошибке, согласованность редактора, пустые/частичные результаты, время/помощь в тоннаже, проверку замеров, настройки и восстановление состояния.

Robolectric/Compose проверяют экраны, формируют UI-превью. Это не физическое устройство: поведение системной клавиатуры, фактическое уничтожение процесса Android, TalkBack и жесты на реальном телефоне требуют проверки тестового APK. Это границы проверки, а не объявление этих сценариев сломанными.

Тестовая установка имеет отдельные данные. История основной FitClub автоматически в неё не переносится. Переключение единиц пересчитывает всю историю именно той установки, в которой оно выбрано.

Room schema 7: миграция сохраняет историю и планы; новые поля имеют значения по умолчанию. Старые записи без снимка или позиции блока не получают выдуманных данных.
