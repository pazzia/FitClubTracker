# Мужской атлас скелетных мышц — рабочая база 0.1

**Это незавершённая БД, а не полный проверенный иллюстрированный атлас.**

## Что находится в архиве

- `muscles.sqlite` — SQLite 3, UTF-8. Все включённые изображения хранятся внутри БД в `assets.content` (BLOB). Внешние ссылки для их загрузки не нужны.
- `catalog.csv`, `catalog.json` — экспорт записей без двоичных изображений.
- `preview.png` — последний вариант оформления с выделением мышцы, русскими/латинскими подписями и фитнес-фильтром.
- `coverage.json`, `MISSING.csv` — фактическое наполнение и перечень недостающих данных.
- `schema.sql` — структура БД.
- `export_images.py` — выгрузка исходных PNG из БД, требует только Python 3.
- `sources/TA2-Part-2.pdf` — неизменённый официальный документ FIPAT, версия 2.07.

## Фактическая готовность

274 записи о мышцах, сериях мышц, комплексах и компонентах; это НЕ 274 отдельных мышцы и не количество мышц с учётом правой и левой стороны. Серии межрёберных, межкостных и червеобразных мышц ещё не разбиты на индивидуальные карточки. Включены некоторые непостоянные варианты. Женские специфические мышцы, гладкая мускулатура и миокард в мужской выборке не представлены.

В справочной таблице `reference_terms` находятся все 798 терминов главы о мышечной системе (1974–2771), включая фасции, сухожилия, части мышц и другие структуры. Это контрольный реестр источника, а не 798 мышц. Русские названия в `muscles` — рабочий перевод, не официальная русская редакция TA2. Полнота выделения именно мышц и их частей из источника ещё требует отдельной проверки.

165 записей помечены `fitness=1`. У 40 записей есть связи с черновыми макетами. В БД включены 17 досок макетов; одна доска может содержать несколько карточек. Доски не выданы за отдельные законченные анатомические иллюстрации. Полная текстовая карточка заполнена только для бицепса; для круговой мышцы глаза заполнена часть текста. Остальные анатомические поля имеют NULL, а не вымышленные сведения.

**Готовых к публикации, анатомически проверенных карточек: 0.** Все рисунки требуют проверки. Известные ошибки внесены в `review_issues`; соответствующие доски имеют `review_status='known_issue'`. Предыдущие эскизы включены для учёта и доработки, а не как подтверждённый анатомический материал.

## Правило fitness

Это редактируемая продуктовая классификация `strength_and_stabilizers_v1`, а не медицинский стандарт. Включены основные мышцы силовых движений, мышцы хвата, стабилизаторы позвоночника, шеи, плечевого пояса, таза и стопы; диафрагма и выбранные компоненты тазового дна. Непостоянные варианты и большинство мимических, глазодвигательных, слуховых, язычных, глоточных и гортанных мышц исключены. Причина решения сохранена в каждой записи. `fitness=0` не означает, что мышца не участвует в физической активности. Флаг не является рекомендацией изолированно тренировать мышцу.

## Требования к будущим рисункам

Выбранная мышца выделена терракотовым цветом, окружающие структуры приглушены серым. Мышца показана крупно, включая малые и глубокие мышцы. Подписи на самой иллюстрации — русский и латынь. На карточке виден признак fitness. Изображение должно иметь подтверждённые начало, прикрепление и ход волокон. Только `board_01` демонстрирует последнее оформление; остальные макеты требуют приведения к нему.

## Использование

Откройте `muscles.sqlite` в любом просмотрщике SQLite. Для извлечения PNG:

```sh
python3 export_images.py
```

Изображения появятся в папке `images`. Связь с мышцами находится в `muscle_assets`: `panel` — позиция карточки на общей доске, не координаты обрезки.

Примеры запросов:

```sql
SELECT id,name_ru,name_la,region_ru,fitness FROM muscles WHERE fitness=1;
SELECT m.name_ru,a.filename,a.review_status,ma.panel
FROM muscles m JOIN muscle_assets ma ON ma.muscle_id=m.id
JOIN assets a ON a.id=ma.asset_id WHERE m.ta2_id=2464;
SELECT * FROM publishable_catalog; -- сейчас пусто
```

`content_status`, `translation_status`, `image_status` и `anatomy_status` независимы. NULL означает отсутствие заполненных данных. `source_checked_not_expert_reviewed` означает сверку текста с указанным источником, но не экспертную проверку рисунка. Не заменяйте эти статусы единым флагом «готово».

Факты для двух текстовых примеров сверены со статьями StatPearls, ссылки находятся в таблице `sources`. Тексты статей и их иллюстрации не скопированы. Изображения в `assets` — сгенерированные в этом диалоге концептуальные макеты, не изображения FIPAT или OpenStax. Материалы OpenStax в архив не включены.

Проверены: целостность SQLite, внешние ключи, уникальность идентификаторов, флаги fitness, размеры и контрольные суммы PNG. Эти технические проверки не подтверждают анатомическую точность.
