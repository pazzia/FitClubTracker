# Правила вёрстки (Compose)

- **Цвета** берутся из `Fc.*` (`ui/theme/Theme.kt`). Палитра `FcPalette` переключает светлую и тёмную темы и акцент. Новый цвет добавляйте в `FcPalette`; литералы `Color(0x…)` в экранах не добавляйте. Цвет текста на заливке — `Fc.on(fill)` / `foregroundFor`.
- **Шрифты**: Onest (`Sans`) для текста, Oswald (`Condensed`) и `NumberStyle` для чисел, с табличными цифрами (`tnum`). Используйте `MaterialTheme.typography`, а не голые `fontSize`.
- **Подписи кнопок и заголовки** пишутся с заглавной только первой буквы («Начать тренировку», не «Начать Тренировку»). Это закреплено тестами.
- **Касание** не меньше 48 dp, основные кнопки 56 dp (единый размер с версии 0.7.0).
- **Адаптивность**: никакой горизонтальной прокрутки и обрезанных столбцов. Степперы и календарь сжимаются на узких экранах (с версии 0.9.2). Проверяйте ширину 360 dp и 320 dp, масштаб шрифта 200 %, обе темы.
- **Доступность**: у иконок без текста есть `contentDescription`, у интерактивных картинок (атлас, карта тела) — подписи для TalkBack. Контраст текста ≥ 4.5:1, крупного текста и иконок ≥ 3:1.
- **Медиа упражнений**: превью из `exercise_thumbnails` (с усиленным контрастом, `docs/THUMBNAIL_CONTRAST.md`), детальные фото — оригиналы `free_exercise_db`. `ContentScale.Fit`, чтобы тренажёр был виден целиком.
- **Состояния**: каждый экран описывает загрузку, пустое состояние («нет тренировок», «ничего не найдено»), ошибку и активную тренировку. Удаление — только с подтверждением.
- Новый экран начинайте со спеки по шаблону `.claude/templates/ux-spec.md`.
- Состояние живёт во ViewModel и репозиториях. Composable не пишет в базу напрямую.
