# Бэклог FitClub

Идеи для развития и коммерциализации. Не в работе — к обсуждению.

## Функции для пользователя
- [ ] **Карта нагрузки и восстановления.** 3D-модель показывает, какие мышцы нагружены за неделю, какие недогружены, какие ещё не восстановились.
- [ ] **Автопрогрессия.** Подсказка веса и повторов на следующую тренировку по истории и самочувствию; разгрузочная неделя при застое.
- [ ] **Проверка техники камерой.** Подсчёт повторов и подсказки по ошибкам на устройстве (Google ML Kit, без отправки видео).
- [ ] **QR-коды на тренажёрах.** Скан в зале открывает карточку упражнения и записывает подход; клубу — статистика загрузки оборудования.
- [ ] **Готовность к тренировке.** Утренний балл по сну, пульсу, шагам и весу из Health Connect и умных весов.
- [ ] **Клубные челленджи.** Лидерборды внутри клуба с учётом веса тела, серии посещений, командные соревнования.
- [ ] **Покупка программ.** Перенесено из MVP.
- [ ] **Анимации техники** для карточек упражнений.
- [ ] **Облачная синхронизация и аккаунты.**

## Коммерческие модели
- [ ] **Приложение для клубов под их брендом (B2B).** Оплата за точку или активного участника; запись к тренерам, абонементы, панель удержания с прогнозом ухода клиентов.
- [ ] **Кабинет тренера.** Назначение программ, просмотр подходов клиентов, комментарии; продажа персональных тренировок с комиссией.
- [ ] **Pro-подписка.** Автопрогрессия, карта восстановления, проверка техники, расширенная аналитика; базовый трекер бесплатный.
- [ ] **Маркетплейс программ.** Авторские программы тренеров с комиссией; оценка соответствия цели как знак качества.
- [ ] **Корпоративный фитнес.** Доступ сотрудникам через работодателя, обезличенная статистика для HR.

## Открытые вопросы
- Приоритет монетизации: B2B для клубов или подписка пользователей?
- Порядок внедрения (предложение: карта восстановления → автопрогрессия → пилот с одним клубом).
