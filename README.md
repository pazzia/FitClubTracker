# FitClub 0.7.0 — трекер тренировок для Android

Единственный актуальный источник приложения: **[pazzia/FitClubTracker](https://github.com/pazzia/FitClubTracker), ветка `main`**.
Версия задаётся в `app/build.gradle.kts`: `versionName = "0.7.0"`, `versionCode = 17`.
Идентификатор установленного приложения: `com.fitclub.tracker`; название: **FitClub**.
Рабочие ветки и старый репозиторий Fitness не являются отдельными актуальными продовыми версиями.

Kotlin · Jetpack Compose · Material 3 · Room · Navigation Compose.
Android 9+ (minSdk 28), compileSdk / targetSdk 34. Данные и фотографии упражнений доступны локально; видео открывается во внешнем приложении и требует интернета.

## Что входит в 0.7.0

- Календарь: нажатие на дату показывает запланированные и выполненные тренировки; планирование начинается отдельной кнопкой.
- Несколько тренировок в один день, каждый план и результат имеют собственный ID.
- Удаление планов и результатов долгим нажатием с подтверждением. При удалении результата связанный план удаляется, если на него больше не ссылаются другие результаты.
- Результат тренировки: выполненные подходы, длительность, общий тоннаж, время упражнений, самые тяжёлые подходы и сравнение с предыдущими рекордами.
- Редактирование результата обновляет выбранную сессию, не создавая дубликат; можно менять веса, повторения, отметки выполнения, подходы и общую длительность.
- Начало тренировки открывает обзор упражнений. Можно начать с любого упражнения и вернуться к списку; ввод сохраняется в рамках текущего процесса приложения.
- Изменение порядка упражнений удержанием ручки перетаскивания или стрелками; добавление и удаление упражнений с подтверждением.
- Завершение доступно с начала тренировки. Сохраняются отмеченные подходы; упражнения на время не входят в весовой тоннаж.
- Единые 56 dp кнопки основных действий и миниатюры в плане.
- Программы с днями A/B/C, целями, подходами, повторениями, отдыхом, комментариями и своими обложками.
- Справочник с поиском, категориями, техникой, заменами, фотографиями и мужским/женским мышечным атласом.
- Светлая и тёмная темы, профиль, замеры тела и статистика.
- Исправления анатомических карточек, фона светлой темы и миниатюр из предыдущих веток сохранены.

## Сборка и установка

[Android CI](https://github.com/pazzia/FitClubTracker/actions/workflows/android.yml) запускается при push в main, для pull request и вручную.
CI проверяет изображения, выполняет тесты, собирает debug APK и выводит сертификат подписи.
В успешном запуске откройте Artifacts → `FitClub-v0.7.0-buildN-debug`: внутри ZIP находится APK.
Артефакты хранятся 14 дней. Debug APK — текущий канал распространения; магазинная release-сборка этим workflow не публикуется.

APK 0.7.0 использует идентификатор основного FitClub и повышенный versionCode. Обновление поверх старого основного APK требует совпадения подписи.
**Не удаляйте установленный основной FitClub ради обновления:** данные локальные.
[Установка и перенос данных](docs/INSTALL_UPDATE.md), [подпись](docs/SIGNING.md).
Ранее установленный «FitClub · Тест» имеет отдельный идентификатор и отдельные данные; автоматического переноса из него в основной FitClub нет.

## Хранение и миграции

Room schema 6. Миграция 5 → 6 сохраняет существующие планы и снимает ограничение одной тренировки на дату.
Настройки профиля сохраняются локально. История, программы и планы хранятся в Room.
Активная незавершённая тренировка пока хранится в ViewModel: после уничтожения процесса Android ввод не восстанавливается.
Единицы веса пока применяются не во всех отчётах; это ограничение текущей версии.

## Разработка

Нужны JDK 17, Android SDK 34 и Gradle 8.9.
В репозитории отсутствует gradle-wrapper.jar; CI устанавливает Gradle отдельно.

```bash
gradle testDebugUnitTest
gradle assembleDebug
```

Фотографии подготавливаются из зафиксированного upstream-архива с проверкой SHA-256.
Модели сегментации используются только при подготовке ресурсов и не включены в APK.
[Каталог упражнений](docs/FREE_EXERCISE_DB.md), [визуальные ресурсы](docs/V0.6.5_UI.md).
