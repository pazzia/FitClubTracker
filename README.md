# FitClub 0.11.0 — программы, тренировки и статистика

Версия: **0.11.0**, `versionCode = 32`. Изменения проверяются в тестовой ветке перед слиянием в `main`.

CI собирает основную установку `com.fitclub.tracker` для `main`/`master` и
тестовую `com.fitclub.tracker.experimental`, **FitClub · Тест**, для pull request и остальных веток.
Тестовая версия имеет суффикс `-test`, устанавливается рядом с основной; данные независимы.
Для обновления существующей установки нужна совпадающая подпись.

Kotlin · Jetpack Compose · Material 3 · Room · Navigation Compose.
Android 9+ (minSdk 28), compileSdk / targetSdk 34. Данные и фотографии упражнений доступны локально; видео открывается во внешнем приложении и требует интернета.

## Что изменено в 0.11.0 — дизайн Iron & Lime из анимационного пакета

- Оформление по пакету FitClubTracker Animation Pack v1: лаймовые кнопки-капсулы с мягким свечением, карточки со скруглением 20dp, тёмный фон с лаймовой подсветкой, Oswald для заголовков и Onest для текста.
- «Сегодня» по макету: аватар, серия недель, карточка тренировки с фото первого упражнения, прогрессом недели и планом подходов (прошлый результат — под названием упражнения), «План недели» плитками, сводка время/тренировки/тоннаж.
- Отсчёт 3–2–1–GO перед новой тренировкой: кольцо с 48 делениями, вибрация на каждом шаге, щелчок на «GO». Нажатие на экран начинает сразу. Отсчёт и звуки отключаются в профиле. С системной настройкой «Убрать анимацию» шаг 700 мс, без частиц и пульсации.
- Итог после тренировки: галочка, расходящиеся кольца, «Отличная работа, имя», время, упражнения и тоннаж с подсчётом, карточка серии. Кнопки «Смотреть прогресс» и «На главную» появляются после анимации. Подробности тренировки и редактирование — ниже.
- Тайминги анимаций берутся из `assets/animations/fitclub_animations.json` (конфиг пакета).
- Профиль — пятая вкладка нижнего меню. Единый переключатель темы, уровни «Новичок / Опытный / Профи».
- Правильные формы слов: «1 подход», «2 упражнения», «21 упражнение».
- Дизайн проверен в два круга; рекомендации и решения — в [docs/V0.11.0_IRON_LIME.md](docs/V0.11.0_IRON_LIME.md).

## Что изменено в 0.9.2

- Следующий подход сам подставляет вес, только что поднятый в предыдущем (кроме подходов, изменённых вручную).
- Суперсет в отдельном подходе: «Как выполнить подход» → «Суперсет» → выбрать упражнение из плана или поиском. На карточке подхода появляются вес и повторы второго упражнения; оно сохраняется в истории как отдельный подход.
- Дропсет понятнее: при выборе сразу появляются три ступени (основной вес и две легче), шаг снижения −10/−20/−30%, подсказка «без отдыха»; кнопка «Дропсет выполнен · N ступ.».
- Режим подхода применяется сразу по нажатию — «Применить» больше не нужно, кнопка «Готово» только закрывает окно.
- Календарь и другие экраны подстраиваются под ширину устройства: без горизонтальной прокрутки и обрезанных столбцов; степперы уменьшаются на узких экранах.
- Справочник мышц обновлён по проверке фитнес-MVP от 11.10.2026: 120 карточек, 45 новых иллюстраций, 9 схем начала и прикрепления, состав и части мышц, синонимы в поиске.
- Внизу справочника — ростовой атлас (мужской или женский по профилю): нажатие на мышцу открывает её карточку.
- Пересборка справочника: `python3 tools/atlas/build_atlas.py fitness-mvp-verified.html exact-schematics.json`.

## Что изменено в 0.9.1 — атлас мышц

- Новый атлас в Справочнике: 12 фитнес-групп и 121 мышца из каталога «Атлас мышц 0.6» — рисунок с выделенной мышцей, где находится, что делает, роль в фитнесе и особенности строения.
- Каждая мышца кликабельна: из плитки группы, из поиска (русский и латынь) и листанием «Предыдущая / Следующая» внутри группы.
- В карточке мышцы — упражнения из справочника приложения с отметкой «основное» или «помогает» и переходом в карточку упражнения. У большой грудной и дельтовидной есть фильтр по частям мышцы. Для мелких и глубоких мышц, которые отдельно не тренируют, — пояснение вместо списка.
- Прежний черновой атлас (274 записи БД 0.1 и 17 макетов-досок) удалён. Данные: `app/src/main/assets/atlas/atlas.json`, рисунки — `atlas/mNNN.webp` и миниатюры `atlas/mNNN_thumb.webp`.
- Анатомия проверена ИИ по справочникам, подбор упражнений — черновик; оба требуют экспертной проверки.

## Что изменено в 0.9.0 — редизайн Iron & Lime

- Стартовый экран «Сегодня»: неделя, следующий день активной программы (A → B → C) и старт тренировки одним касанием. Вкладки: Сегодня, Программы, Справочник, Прогресс; календарь открывается из полосы недели, профиль — по аватару.
- Тренировка открывается сразу на первом упражнении. Текущий подход вводится крупными кнопками ±2,5 кг и ±1 повтор (значение можно и напечатать), рядом — результат прошлой тренировки; выполненные подходы сворачиваются в строки.
- Отдых закреплён внизу экрана, есть полноэкранный таймер, ±15 секунд и вибрация по окончании. Экран не гаснет во время тренировки.
- После завершения сразу открывается итог: время, объём, подходы и новые рекорды.
- План тренировки: перестановка и удаление — в режиме «Изменить».
- Справочник: фильтр по оборудованию, недавние упражнения, количество в фильтрах, «+» для добавления в программу из списка, техника по шагам и вкладки «Техника · Мышцы · Замены».
- Прогресс: объём за неделю с изменением к прошлой, регулярность за 12 недель.
- Новая визуальная система в тёмной и светлой темах; шрифты Oswald (цифры и заголовки) и Onest (интерфейс) встроены в приложение, лицензия — `docs/FONTS_LICENSE.md`.
- Исправлено: заставка 0,8 с при каждом запуске, пометка «Тестовая версия» в заметках основной сборки, счётчик тренировок в профиле учитывал пустые сессии, цвета системных панелей не совпадали с фоном, фантомный отдых после восстановления черновика.
- CI публикует ошибки компиляции и упавшие тесты аннотациями к PR.
- «Сегодня» больше не выдаёт программу за план: без плана показывается статус дня (день отдыха, цель недели, сколько осталось), а следующий день программы — отдельным предложением. Демо-программы не становятся активными сами.
- Прошлый результат и рекорд над подходами; режимы заполнения «Пусто / Повторить / +2,5 кг»; история упражнения с рекордом, лучшим подходом и оценкой 1ПМ, заполнение по любой из последних тренировок.
- Техники подходов: разминка, дропсет и рест-пауза со ступенями, до отказа, негативы, частичные повторы — для одного, последнего или всех подходов; задаются и в программе. Рекорд дропсета — по первой ступени, тоннаж — по всем.
- Суперсеты: связка упражнений в плане и в программе, автоматический переход между упражнениями круга, отдых — после круга.
- Суперсет можно собрать из любых упражнений дня, не только соседних (Room schema 9, номер группы суперсета).
- Дробные числа: ввод принимает и запятую, и точку, сохраняется и показывается с запятой; до двух знаков (диски 1,25 кг).
- В итоге тренировки нажатие на упражнение открывает карточку: все подходы с техникой и ступенями, рекорды, время, редактирование только этого упражнения.
- Снимки экрана разрешены явно (FLAG_SECURE снимается).
- Удаление программ: смахивание влево для одной, удержание — режим выбора («Выбрано N», «Все», плавающая панель «Удалить»), подтверждение в нижней панели со списком программ, числом тренировок и предупреждением об активной программе, отмена «Вернуть» в течение 5 секунд. Порядок программ больше не сбивается после редактирования.

## Возможности приложения

- Календарь: нажатие на дату показывает запланированные и выполненные тренировки; планирование начинается отдельной кнопкой.
- Несколько тренировок в один день, каждый план и результат имеют собственный ID.
- Удаление планов и результатов долгим нажатием с подтверждением. При удалении результата связанный план удаляется, если на него больше не ссылаются другие результаты.
- Результат тренировки: выполненные подходы, длительность, общий тоннаж, время упражнений, самые тяжёлые подходы и сравнение с предыдущими рекордами.
- Редактирование результата обновляет выбранную сессию, не создавая дубликат; можно менять веса, повторения, отметки выполнения, подходы и общую длительность.
- Начало тренировки открывает обзор упражнений. Можно начать с любого упражнения и вернуться к списку; ввод сохраняется в локальном черновике тренировки.
- Изменение порядка упражнений удержанием ручки перетаскивания или стрелками; добавление и удаление упражнений с подтверждением.
- Завершение доступно с начала тренировки. Сохраняются отмеченные подходы; упражнения на время не входят в весовой тоннаж.
- Единые 56 dp кнопки основных действий и миниатюры в плане.
- Программы с днями A/B/C, целями, подходами, повторениями, отдыхом, комментариями и своими обложками.
- Справочник с поиском, категориями, техникой, заменами, фотографиями и мужским/женским мышечным атласом.
- Светлая и тёмная темы, профиль, замеры тела и статистика.
- Исправления анатомических карточек, фона светлой темы и миниатюр из предыдущих веток сохранены.

## Сборка и установка

[Android CI](https://github.com/pazzia/FitClubTracker/actions/workflows/android.yml) запускается при push в main, для pull request и вручную.
CI проверяет изображения, выполняет тесты, собирает debug APK, проверяет package/version и выводит сертификат подписи.
В успешном запуске откройте Artifacts → `FitClub-v0.8.1-buildN-debug` (main) или `FitClub-v0.8.1-test-buildN-debug` (тестовая ветка): внутри ZIP находится APK.
Артефакты хранятся 14 дней. Debug APK — текущий канал распространения; магазинная release-сборка этим workflow не публикуется.

APK из main обновляет основную установку. APK из pull request обновляет тестовую установку.
Обновление сохраняет локальные данные; удаление приложения для установки не требуется при совпадающей подписи.

## Хранение и миграции

Room schema 7. Миграции сохраняют существующие планы и историю, добавляют черновики и метаданные результата.
Планы не переписываются при завершении; фактический результат и название получают собственный снимок.
Единицы переключаются без изменения сохранённых весов. В открытых редакторах единицы ввода фиксированы до завершения.

## Разработка

Нужны JDK 17, Android SDK 34 и Gradle 8.9.
В репозитории отсутствует gradle-wrapper.jar; CI устанавливает Gradle отдельно.

```bash
gradle testDebugUnitTest
gradle assembleDebug  # основная установка
gradle -PfitclubExperimental=true assembleDebug  # тестовая установка
```

Фотографии подготавливаются из зафиксированного upstream-архива с проверкой SHA-256.
Модели сегментации используются только при подготовке ресурсов и не включены в APK.
[Каталог упражнений](docs/FREE_EXERCISE_DB.md), [визуальные ресурсы](docs/V0.6.5_UI.md).
