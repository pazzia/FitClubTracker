# FitClub — трекер тренировок (MVP, Android)

Kotlin · Jetpack Compose · Material 3 · Room · Navigation Compose. minSdk 28, targetSdk 34.

## Автоматическая сборка через GitHub
Workflow `.github/workflows/android.yml` запускается при каждом push в `main`, для pull request и вручную через **Actions → Android CI → Run workflow**.

После успешной сборки откройте запуск workflow и скачайте **Artifacts → fitclub-debug-apk**. Внутри ZIP находится устанавливаемый debug APK. GitHub хранит артефакт 14 дней.

Сборка использует JDK 17, Android SDK 34 и Gradle 8.9. Сначала выполняются unit-тесты, затем собирается APK. Секреты для debug-сборки не нужны.

## Как запустить локально
1. Откройте папку в Android Studio (Koala или новее).
2. Если студия сообщит об отсутствии `gradle-wrapper.jar`, нажмите **Sync**. Для CI Gradle 8.9 устанавливается самим workflow.
3. Запустите конфигурацию `app` на эмуляторе или телефоне.
4. Тесты логики оценки программ: `./gradlew test`.

При первом запуске база заполняется справочником (52 упражнения, 11 групп мышц) и тремя примерами программ.

## Что готово (этап 1)
- **Справочник:** группы мышц с мини-моделью → список группы с блоком «Целевая зона» и фильтрами «Тип / Уровень» без прокрутки → карточка упражнения: 3D-модель спереди и сзади (мужская/женская), целевые мышцы красные с синим свечением, вспомогательные оранжевые, мышечные волокна и вены, техника, воздействие, сложность, рейтинг сообщества (пока псевдослучайный), замены. Поиск по названию.
- **Программы:** неограниченное число программ, название, цвет, обложка, цель, частота, дни A/B/C…, подходы/повторы/отдых, выбор упражнений из справочника, живая оценка соответствия цели в процентах с разбором по 6 критериям и конкретными рекомендациями. Активная программа.
- Тёмная тема Volt Night, нижняя навигация.

## Дальше

## Структура
```
data/model   — перечисления: мышцы, группы, цели, диапазоны повторений
data/db      — Room: сущности, DAO, база
data/seed    — стартовый справочник упражнений
data/repo    — репозитории, черновик программы, примеры программ
domain       — ProgramScorer: оценка программы под цель
ui/components— модель тела (Canvas), общие элементы
ui/library   — справочник
ui/programs  — программы и конструктор
ui/navigation— навигация и нижнее меню
```
