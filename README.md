# FitClub — трекер тренировок 0.4.0 (Android)

Kotlin · Jetpack Compose · Material 3 · Room · Navigation Compose. Android 9+ (minSdk 28), targetSdk 34.

## Автоматическая сборка
Workflow .github/workflows/android.yml запускается при push в main, для pull request и вручную через Actions → Android CI → Run workflow.
После успешного запуска скачайте Artifacts → FitClub-v0.4.0-buildN-debug. В ZIP лежит APK с тем же именем. Версия берётся из метаданных APK, номер — из GitHub Actions. Артефакт хранится 14 дней.

CI использует JDK 17, SDK 34 и Gradle 8.9. Сначала выполняются тесты, затем собирается APK. Подпись проверяется до сборки и в готовом файле; потеря нужного ключа останавливает публикацию. [Установка и перенос старых данных](docs/INSTALL_UPDATE.md).

## Возможности
- Календарь — главный экран: кликабельные даты, план выбранного дня, создание и редактирование тренировки.
- Программы: дни A/B/C, упражнения, подходы/повторы/отдых, комментарии, фотообложка, цель и разбор программы с итогом внизу.
- Добавление упражнения: сетка категорий с изображениями → упражнения выбранной группы, поиск и фильтр типа.
- Справочник: категории, техника, замены и мышечный атлас. Пол модели задаётся в профиле.
- Активная тренировка: веса, повторы, дополнительные подходы, таймер отдыха и сохранение результата. Комментарий виден во время выполнения.
- Прогресс: история, тоннаж, лучшие подходы, недельная динамика и замеры тела.
- Профиль: пол, замеры, уровень, оформление и единицы.
- Программы, планы, история, замеры и фото сохраняются локально. Room 4 мигрирует данные предыдущих версий.

## Обновления 0.4.0
Перерисованы женский атлас, ягодицы и квадрицепсы с показом четырёх головок. Значок приложения — вариант №2 из предоставленного эскиза. Камера запрашивает разрешение; галерея выбирает одно фото после согласия. [Все изменения](docs/V0.4_CHANGELOG.md).

## Локальная разработка
Откройте проект в Android Studio. Требуются полный JDK 17, Android SDK 34 и Gradle 8.9; в CI Gradle устанавливается workflow, gradle-wrapper.jar в репозитории отсутствует.
Проверка: gradle testDebugUnitTest. Сборка: gradle assembleDebug.
